## Rolling與停止

包排序是準備順序，不額外增加整包完成障礙；按原364條Unit DAG及已接受result或合法reuse決定。先準備下一個dependency frontier的精簡候選，固定source cache與delta；不在waiting review時擅自跳原lane或開新execution。未變更Context不重新編全部，遇變更只失效真正相關closure。Milestone僅MVP／Normal／Complete B3，完整B3義務不減少。

一般命名、內部實作、合格工具切換提案、影響測試選擇與既有budget內普通修正由WORK/Executor按原權限處理，無需Ultra。需變更authority/受保護semantics/重大跨章節接口/資金安全或無原始來源則固定最小反例與影響範圍，交既有Owner/Human；Architecture能力可由任何合格替代者承擔，不能把特定模型額度當永久gate。禁止無限拆碎或無限重試；超過授權budget停受影響工作。
