## 確認的規則與實作

1. 桌面內容寬度以完整內容區計算，從左至右固定 **5% 空白／30% 色輪欄／10% 欄距／50% 色票欄／5% 空白**。用同一份 CSS Grid 位置給上、下排；不是套用各種 `left` 偏移。
2. Color Wheel Tool 標題列高度約為下方頁籤列的 2 倍以上（例如 1440px 時 78px 對 34px）；標題沿用動態強調色。
3. 色輪底部與五色色票底部使用相同的基準線。桌面寬 1440／1343／1180／1104px 的實測底線差都是 0px。
4. 七個調和模式沿用原 ICON，只顯示 ICON，整列寬度等於色輪寬度。
5. 色票下方工具列以與上方**完全相同的五欄網格**排列：第一欄只放色板下拉＋刪除；第二、三欄留空；第四欄只放迷你色帶；第五欄只放名稱文字輸入與儲存 ICON。
6. 在窄視窗（<=1060px）改成上下排列並允許滾動；不把五欄強擠到無法操作的尺寸。600px 另調整窄版控制區占欄。
7. 保留既有整片半透明編輯背景與配色事件，沒有產生任何示意圖片交付。
